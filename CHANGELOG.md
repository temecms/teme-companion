# Changelog

## 0.3.0 — 2026-11-21

### Added

- The `languages` route: Polylang's languages in its order, its settings, the menus per language and the translated site title and tagline, as plain JSON. Teme's import reads it to bring a Polylang site across with every language, each post and term in its language and its translations linked.

## 0.2.0 — 2026-11-15

### Added

- The read-only export API Teme's importer reads: settings, people, terms, media, content, comments, menus, redirects and addresses, for an administrator's application password over HTTPS.

## 0.1.0

- The site report: a one-time scan of the site's structure, content, settings and plugins, as a JSON file to download and review.
